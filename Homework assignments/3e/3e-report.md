For this project, I used myteam to build a game. I had a developer, a lead
UI designer, the main agent, a team constructor and a project planner to work on the game. As a comparison I also had 
codex build the same game by itself. I found myteam to be a lot more efficient and the 
game looked and functioned much better. The team constructor was able to make new team members and 
skills for team members as it say fit to get the project done.
