While looking into ways in which AI is being implemented, I ran into 
articles about anthropics Project Glasswing. This project is using its newest model 
that is not released to the public but is available to some companies to improve their 
infrastructure and security. The reason that they are doing this is becasue the new model 
is very good at identifying security vulnerabilities and bugs. They are not releasing it to the 
public until large companies such as apple crowdstrike, google and JPMorgan have been 
able to use it to identify and fix security vulnerabilities. I think that this 
is a great use of AI as the model is able to identify and try more possibilities 
than a human can. This is especially important in the field of security where new vulnerabilities are being
discovered every day.
