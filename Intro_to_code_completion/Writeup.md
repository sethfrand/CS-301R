For this assignment I wrote the simple single response program and 
then played around with how to have the program respond to different inputs. With the 
first prompt, I wanted to see how good it was at code generation, it seemed to work fairly well. 
with my second prompt, I wanted to see how the agent would respond to different questions. Originally I only 
had a few questions, and they were all related (the questions about Tolstoy), and the responses were quite lengthy. 
I then changed the prompt to include 30 additional questions that were not related at all. With the gpt-5-nano
model, the responses to the questions about Tolstoy got quite a bit shorter. I then wrote a third prompt 
just for fun where I asked the agent to answer each question as if it were Tolstoj. When I was satisfied with that
I decided to interrupt at different intervals having it respond in a different language. It had a hard time 
going back to English, but it was able to generate a lot of interesting responses. Watching the video and 
reading the recommended reading also helped me to better understand the backend of a model. A lot of it reminded of
the concepts that I learned in CS-270 (intro to Machine Learning). With comparing different models, I had 
each one tell me a short story. I thought it was interesting that the gpt-3.5-turbo model generated a longer story 
than the gpt gpt-4.1-nano model. Overall I thought this assignment was fun and informative.
